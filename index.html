TagFusion est en ligne ✅

Recherche par tags fusionnés sur plusieurs sites, pour Paperback 0.8.

Adresse à coller dans Paperback :
  1. Paperback → Réglages → Sources externes → + → colle l'adresse.
  2. Installe TagFusion.
  3. Dans les réglages de TagFusion : Mes sites → colle tes sites, puis Charger / mettre à jour les tags.
